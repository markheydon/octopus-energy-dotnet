# REST and GraphQL

Most of the **published** NuGet package today is **REST** (latest **1.1.0**; milestones **v1.0** and **v1.1**). **GraphQL customer extras** are implemented on `main` for milestone **v1.2** and will ship as NuGet **1.2.x** (not package **2.0.0**). See [release labels](../../VERSIONING.md#release-labels-quick-reference) and [API coverage](../reference/api-coverage.md) (*NuGet vs source*).

Callers should still construct a single `OctopusEnergyClient` with an API key. The SDK exchanges that key for a Kraken JWT internally when a GraphQL-backed call needs it — you do not choose REST versus GraphQL per call, and you do not attach GraphQL tokens yourself.

Public GraphQL-backed capabilities (on `main`; NuGet **1.2.x** when tagged) are **`client.Viewer`** (discover account numbers via `viewer`), **`client.RateLimits`** (hourly complexity points allowance and remaining balance via `rateLimitInfo`), **`client.MeterReadings`** (electricity and gas reading submission plus `readingConsentGranularity` lookup), **`client.AccountBilling`** (Relay lists for bills, transactions, and payments on `account`), **`client.Devices`** (SmartFlex device lists and `flexPlannedDispatches`), **`client.SmartMeterTelemetry`** (EUI64 discovery and `smartMeterTelemetry`), **`client.Octoplus`** (enrolment, loyalty points, wheel-of-fortune allowance, and related mutations on the public host), and **`client.ProductSwitch`** (`initiateProductSwitch` when the key is permitted). Saving-session join APIs are not on the public GraphQL schema. Constants for Relay paging and operational limits live on `GraphQlRelayLimits`; see [pagination](../how-to/pagination.md).

Do not expose GraphQL query strings or REST URL templates on the public surface. See [adr-0001](../../adr/adr-0001-customer-sdk-dual-transport.md).
