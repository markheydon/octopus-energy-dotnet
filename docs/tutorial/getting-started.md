# Getting started

The SDK is a **compile-only skeleton**. There is no HTTP client yet.

When v1.0 ships, you will:

1. Create an API key in the [Octopus dashboard](https://octopus.energy/dashboard/new/accounts/personal-details/api-access).
2. Install `OctopusEnergy.Client`.
3. Construct `OctopusEnergyClient` with the key.
4. Call resource methods for products, account, and consumption.

Until then, follow feature [#6](https://github.com/markheydon/octopus-energy-dotnet/issues/6) (REST customer core) on milestone [v1.0](https://github.com/markheydon/octopus-energy-dotnet/milestone/1), then feature [#7](https://github.com/markheydon/octopus-energy-dotnet/issues/7) on [v2.0](https://github.com/markheydon/octopus-energy-dotnet/milestone/2).
