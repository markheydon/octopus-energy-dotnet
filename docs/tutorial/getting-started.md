# Getting started

The SDK is a **compile-only skeleton**. There is no HTTP client yet.

When v1 ships, you will:

1. Create an API key in the [Octopus dashboard](https://octopus.energy/dashboard/new/accounts/personal-details/api-access).
2. Install `OctopusEnergy.Client`.
3. Construct `OctopusEnergyClient` with the key.
4. Call resource methods for products, account, and consumption.

Until then, follow GitHub milestones **v1 — REST customer core** and **v2 — GraphQL customer extras**.
