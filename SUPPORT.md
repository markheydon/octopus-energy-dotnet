# Support

## Getting Help

Use [GitHub Discussions](https://github.com/markheydon/octopus-energy-dotnet/discussions) as the primary channel for:

- Setup and usage questions.
- Troubleshooting.
- Design and API usage discussion.
- General project feedback.

## When to Open an Issue

Open a GitHub issue only for confirmed defects, actionable feature requests, or maintenance tasks.

Use the repository templates (bug, feature, chore, story).

## Before Opening a New Thread

- Check [docs/](docs/README.md).
- Check [README.md](README.md) and [VERSIONING.md](VERSIONING.md).
- Search existing issues and discussions.
- For upstream behaviour, check [Octopus API docs](https://docs.octopus.energy/) and the [GraphQL IDE](https://api.octopus.energy/v1/graphql/).

## Security Issues

Do not post vulnerabilities in public threads. Follow [SECURITY.md](SECURITY.md).

## Response Expectations

Support is best-effort.

Please provide:

- SDK version.
- Runtime and OS details.
- Minimal reproduction.
- Relevant errors with secrets removed.
